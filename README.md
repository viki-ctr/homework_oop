# Проект "Интернет-магазин"

## Описание:

Проект "Интернет-магазин" - это веб-приложение на Python для создания и управления покупками. Пользователи могут создавать новые записи, редактировать их.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/viki-ctr/homework_oop.git
```

2. Установите зависимости:
При работе с pip:
```
pip install -r requirements.txt
```
При работе с poetry:
```
poetry install
poetry update
```

## Использование:

1. Откройте приложение в вашем веб-браузере.
2. Создайте новую учетную запись или войдите  в уже существующую.

Функциональность:
1. Реализован модуль product и category с наличием классов Product и Category.
2. В модуль category добавлен метод add_product, с помощью которого добавляются новые продукты.
3. Реализован геттер, который выводит список товаров в виде строк в формате: Название продукта, 80 руб. Остаток: 15 шт.
4. Создан класс-метод new_product, который будет принимать на вход параметры товара в словаре и возвращать созданный 
объект класса Product.
5. Для класса Product к приватному атрибуту написаны геттер и сеттер. В сеттере реализована проверка цены.
6. Для класса Product  реализованы подклассы Smartphone и LawnGrass.
7. В классе Product доработана функциональность сложения.

## Тестирование:
Наш проект тестировался при помощи фреймворка Pytest. Чтобы запустить тестирование проекта, вам нужно:
1. Установить pytest
```
poetry add --group dev pytest
```
2. Запустите тесты:
```
pytest
```
3. Проверить покрытие тестами:
```
poetry add --group dev pytest-cov
poetry run pytest --cov
```
4. Чтобы сгенерировать отчет о покрытии в HTML-формате:
```
pytest --cov=src --cov-report=html
```
