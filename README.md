# Проект "Интернет-магазин"

## Описание:

Проект "Интернет-магазин" - это веб-приложение на Python для создания и управления покупками. Пользователи могут создавать новые записи, редактировать их.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/viki-ctr/homework_oop.git
```

2. Установите зависимости:
При работе с pip:
```
pip install -r requirements.txt
```
При работе с poetry:
```
poetry install
poetry update
```

## Использование:

1. Откройте приложение в вашем веб-браузере.
2. Создайте новую учетную запись или войдите  в уже существующую.

Функциональность:
1. Реализован модуль data с наличием классов Product и Category.

## Тестирование:
Наш проект тестировался при помощи фреймворка Pytest. Чтобы запустить тестирование проекта, вам нужно:
1. Установить pytest
```
poetry add --group dev pytest
```
2. Запустите тесты:
```
pytest
```
3. Проверить покрытие тестами:
```
poetry add --group dev pytest-cov
poetry run pytest --cov
```
4. Чтобы сгенерировать отчет о покрытии в HTML-формате:
```
pytest --cov=src --cov-report=html
```
